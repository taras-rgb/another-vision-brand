# Another Vision: brand workspace

This is the shared space for the Another Vision identity: the final logo and type, plus the explorations so far.

- **Logo:** `brand/logo/` has SVG and PNG files and a one-page sheet (`logo-final-sheet.png`).
- **Type:** Onest, in `brand/fonts/onest/` (free for commercial use under the SIL Open Font License).
- **Colour direction:** A1.2, in `explorations/colour-boards/`.
- **Explorations:** colour boards, logo rounds, social posts and LinkedIn banners.

If you work with Claude Code, open this folder in it. Claude reads `CLAUDE.md` automatically, which has the decisions made so far and the house rules.

## Getting started

```bash
git clone <repo-url>
cd another-vision-brand
claude
```
